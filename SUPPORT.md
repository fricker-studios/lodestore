# Getting help

- **Something is broken, crashes, or lost your items** →
  [file a bug report](https://github.com/fricker-studios/lodestore/issues/new/choose).
  Attach `logs/latest.log` or the crash report; the form asks for it because it is what
  gets the bug fixed.
- **It fights with another mod** → the mod compatibility form, from the same page.
- **How do I…? / Is this intended? / Look what I built** →
  [Discussions](https://github.com/fricker-studios/lodestore/discussions).
- **A player can exploit it on a server** → see [SECURITY.md](SECURITY.md). Do not post it publicly.

Installation: drop the jar from the
[latest release](https://github.com/fricker-studios/lodestore/releases/latest) into
`.minecraft/mods` next to Fabric API. The README's
[Toolchain](README.md#toolchain-verified-2026-08-29-against-live-sources) table lists the
Minecraft, Fabric Loader, and Fabric API versions it is built against.
